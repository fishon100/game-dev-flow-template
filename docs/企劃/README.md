# 企劃文件（基本版：沒有 Notion 時放這裡）

> 有用 Notion 的專案，這些內容改放 Notion（見 `docs/flow/03 Notion 與 GitHub.md`），這個資料夾可以刪掉或當鏡像。
> 需求、回饋不放這裡：用工作台的「提需求」「寫回饋」（GitHub Issue）。

| 檔案 | 內容 | 誰改 |
|---|---|---|
| [主架構規劃書.md](主架構規劃書.md) | 一句話、設計支柱、核心循環、不能改的核心規則 | 企劃 |
| [知識庫/名詞表.md](知識庫/名詞表.md) | 遊戲裡每個東西的正式名稱（回饋、需求都用這些名字） | 企劃、劇本 |
| [開發日誌.md](開發日誌.md) | 每張申請單結案、每次修 bug 的紀錄 | AI |

不會用 git？在 GitHub 網頁打開檔案 → 右上角鉛筆 ✏️ → 改完按「Commit changes」就好（手機也可以）。
