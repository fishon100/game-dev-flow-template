# 01 一輪開發

> 總覽：[00 總覽](00%20%E7%B8%BD%E8%A6%BD.md)。這份是整套流程的主線：**想法 → 申請單 → 同意 → 實作 → 上線 → 試玩 → 結案**。

## 流程圖

```
 ① 想法          ② 討論（選用）      ③ 提案            ④ 企劃同意
 Notion 需求池 ─▶ /spectra-discuss ─▶ /spectra-propose ─▶ Notion「申請單確認」按同意
                                                              │
 ⑧ 結案            ⑦ 試玩回饋          ⑥ 上線通知          ⑤ 實作（TDD）
 /spectra-archive ◀─ Notion 回饋 ◀──── 部署＋手機通知 ◀──── /spectra-apply
   │                  │ 有 🔴 → 回到 ⑤（/spectra-ingest 把新要求併進申請單）
   └─ 規則併回 docs/spectra/specs，開發日誌寫一筆
```

## 每一步誰做、在哪裡、做什麼

| 步驟 | 誰 | 在哪裡 | 做什麼 | 對 AI 說 |
|---|---|---|---|---|
| ① 想法 | 任何人 | Notion「需求池」 | 寫一張卡：想要什麼、為什麼、參考圖 | — |
| ② 討論 | 企劃＋AI | Claude Code | 需求還模糊時，先比較做法，不改程式 | 「討論 <需求卡標題>」 |
| ③ 提案 | AI | GitHub `docs/spectra/changes/<名稱>/` | 寫出申請單 4 份文件（見下），並在 Notion 建一張「申請單確認」卡附中文摘要 | 「把 <需求卡> 開成申請單」 |
| ④ 同意 | 企劃 | Notion「申請單確認」 | 讀摘要與「需要確認的事」，把狀態改成「同意」或寫意見 | 「申請單 <名稱> 同意」 |
| ⑤ 實作 | AI | GitHub | 先寫會失敗的測試 → 寫程式 → 測試全過；任務清單逐項打勾 | 「做 <名稱>」 |
| ⑥ 上線 | AI | GitHub Actions | 推上 GitHub → 自動跑測試 → 部署預覽網址 → 手機收到通知 | （⑤ 做完自動） |
| ⑦ 試玩 | 企劃（＋美術） | 手機 | 打開通知裡的連結試玩，在 Notion「回饋」寫 🔴🟡🟢 | 「看回饋」 |
| ⑧ 結案 | 企劃說 OK → AI | GitHub＋Notion | 規則併回正式規則書、申請單搬到 archive、開發日誌寫一筆 | 「<名稱> 結案」 |

## 申請單的 4 份文件（企劃要看懂的部分）

Spectra 的一張申請單（change）是一個資料夾：

| 檔案 | 寫什麼 | 企劃要看嗎 |
|---|---|---|
| `proposal.md` | **為什麼**要改、**改什麼**、影響哪些功能、需要企劃確認的事 | ✅ 一定要看（Notion 摘要就是它） |
| `specs/<功能>/spec.md` | 改了哪幾條**規則**，每條附「情境：當…則…」 | ✅ 看規則有沒有寫錯 |
| `design.md` | 程式**怎麼做**、為什麼選這個做法 | 選看 |
| `tasks.md` | **待辦清單**，做完一項勾一項（進度就看這裡） | 選看 |

> 規則書（`docs/spectra/specs/`）＝遊戲「現在」的規則。申請單＝「想要改成什麼」。結案時申請單裡的規則會併回規則書。

## 什麼時候不用開申請單

- 純修錯字、改顏色這種**不改規則**的小事：直接說「修 <問題>」，AI 修好、跑測試、部署，在開發日誌記一筆。
- 試玩發現的 bug：AI 用 `/spectra-debug` 先重現、找原因；修法如果改到規則，還是要開申請單。

## 做到一半需求變了

不要另開新的。對 AI 說「<名稱> 改成 …」，AI 會用 `/spectra-ingest` 把新要求寫回同一張申請單，再請企劃確認一次改動的部分。

## 品質關卡（AI 自己會跑，結案前一定過）

| 指令 | 檢查什麼 |
|---|---|
| `/spectra-analyze` | 申請單 4 份文件之間有沒有矛盾、漏掉 |
| `/spectra-verify` | 程式是不是真的照規則、任務、設計做了 |
| `/spectra-review` | 程式審查（只出報告，不改檔）；程式審查員看這份 |
| `/spectra-drift` | 申請單寫的和現在的程式有沒有對不上 |
