# 05 工具與帳號

> 總覽：[00 總覽](00%20總覽.md)。
> 教訓：曾經因為 AI 帳號到期、雲端硬碟連到別人的帳號，花了半天找資料。**帳號表一定要寫，交接一定要照清單。**

## 工具

### 開發
| 工具 | 用途 |
|---|---|
| Claude Code（桌面版 Code 分頁或終端機） | 主控 AI：寫申請單、程式、測試、部署、同步 Notion |
| Spectra（`spxa` 指令＋桌面 App） | 申請單與規則書管理；桌面 App 可以看進度、結案 |
| `/goal` | 給 AI 完成條件，它會一路做到完成、不中途問問題 |
| Remote Control | 電腦上的 Claude 繼續跑，人在手機 Claude App 看進度、下指令 |
| Node.js 22 以上 | 跑測試、同步工具、`spxa` |
| 網頁原型（HTML＋JavaScript） | 最快驗證玩法，手機直接玩；定案後再決定要不要換引擎 |
| Godot／Unity（選用） | 正式版引擎 |
| Codex／Copilot（選用） | 第二家 AI 程式審查 |

### 產出
| 類別 | 工具 |
|---|---|
| 文字：企劃、劇本、台詞 | Claude、ChatGPT |
| 圖：角色、場景、UI 方向稿 | ChatGPT（GPT Image）、Midjourney、Gemini |
| 音樂 | Suno |
| 音效、語音 | ElevenLabs |
| 數值 | Google 試算表／Excel、遊戲內調參面板 |

### 管理與協作
| 工具 | 放什麼 |
|---|---|
| **Notion** | 需求、申請單確認、回饋、知識庫、素材、開發日誌（人寫的正本） |
| **GitHub** | 程式、規則書、申請單、測試、素材檔、這套開發流（AI 執行的正本） |
| **Figma** | 美術設計稿與精修 |
| Google Drive | 大型原始檔（音樂原檔、高解析原圖）、試算表 |

### 預覽與通知
| 工具 | 用途 |
|---|---|
| GitHub Pages | 手機直接開的預覽網址（GitHub Actions 自動部署） |
| ntfy App | 部署成功／失敗推播到手機（GitHub Actions 送出） |
| Windows 通知（`tools/notify.ps1`） | 本機做完事時跳通知（選用） |
| Claude Artifact | 快速分享原型或文件（私人連結） |

## 確認 Claude 連到哪些工具

在 Claude Code 對 AI 說「**檢查連接器**」，它會列出每個工具的連線狀態，並實際讀一個檔案確認**帳號是對的**（例如雲端硬碟裡找得到專案資料夾）。

## 換帳號／換人接手清單

- [ ] 新帳號連好 Notion、Figma、Google Drive 連接器，說「檢查連接器」確認帳號正確
- [ ] `gh auth status` 確認 GitHub 帳號，對 repo 有寫入權限
- [ ] 安裝 `spxa`（`npm install -g @kaochenlong/spxa`），在專案資料夾跑 `spxa init --tools claude`
- [ ] 讀 `CLAUDE.md`、`docs/flow/`、Notion 開發日誌最後 5 筆，就知道做到哪
- [ ] `spxa list` 看有沒有做到一半的申請單
- [ ] 更新上面的帳號表

## 密鑰規則

- 不放進 git：ntfy 主題、API 金鑰、個人設定檔（`.gitignore` 已經擋了 `tools/*.config.json`）
- 放 GitHub Secrets：CI 要用的（`NTFY_TOPIC`）
- 公開 repo 也不要寫本機路徑、個人 email
