# 06 新專案啟動

> 總覽：[00 總覽](00%20%E7%B8%BD%E8%A6%BD.md)。照順序做，大約半天就能有第一個能在手機上玩的版本。

## A. 建 repo（程式負責，10 分鐘）

- [ ] 在 GitHub 打開 `game-dev-flow-template` → **Use this template** → 取新專案名稱
- [ ] 下載到本機：`gh repo clone <帳號>/<專案>`
- [ ] 安裝 Spectra 指令：`npm install -g @kaochenlong/spxa`，在專案資料夾執行 `spxa init --tools claude`
- [ ] repo 的 Settings → Pages → Source 選 **GitHub Actions**
- [ ] （選用）Settings → Secrets → Actions 新增 `NTFY_TOPIC`；手機裝 ntfy App 訂閱同一個主題
- [ ] 改 `docs/spectra/config.yaml` 的 `<遊戲名稱>`、一句話玩法、核心規則

## B. 建 Notion（企劃負責，AI 幫忙，20 分鐘）

- [ ] Claude 連好 Notion 連接器
- [ ] 對 AI 說「**建 Notion 工作區**」→ AI 照 [03 Notion 與 GitHub](03%20Notion%20%E8%88%87%20GitHub.md) 建好頁面與資料庫，把 ID 寫進 `docs/notion.json`
- [ ] 填專案首頁的帳號表（[05 工具與帳號](05%20%E5%B7%A5%E5%85%B7%E8%88%87%E5%B8%B3%E8%99%9F.md)）
- [ ] 邀請團隊成員進 Notion 工作區

## C. 寫核心（企劃負責，1～2 小時）

- [ ] 在 Notion「主架構規劃書」寫：一句話、設計支柱（3～5 個）、核心循環、**不能改的核心規則**
- [ ] 知識庫先建「名詞表」：遊戲裡每個東西的正式名稱
- [ ] 需求池丟第一批想法，標優先

## D. 第一個可玩版本（AI，1～2 小時）

- [ ] 對 AI 說：`/goal 依主架構規劃書，開第一張申請單做出可玩的核心循環，測試全過、部署並通知`
- [ ] AI 會：寫申請單 → 在 Notion 建「待同意」卡 → **等你同意** → 實作 → 部署 → 手機通知
- [ ] 手機試玩，寫第 1 輪回饋 → 對 AI 說「看回饋」

## E. 進入循環

從這裡開始就是 [01 一輪開發](01%20%E4%B8%80%E8%BC%AA%E9%96%8B%E7%99%BC.md) 的循環。建議節奏：
- 每天：企劃看「申請單確認」與試玩
- 每週：說「更新專案首頁」＋「備份」；團隊看一次開發日誌
