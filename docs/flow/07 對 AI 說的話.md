# 07 對 AI 說的話

> 總覽：[00 總覽](00%20總覽.md)。在 Claude Code 直接打這些話就好，AI 讀 `CLAUDE.md` 就知道要做什麼。

## 日常

| 說 | AI 做什麼 |
|---|---|
| 看需求 | 讀 Notion 需求池的新想法，整理後問你要開哪幾張申請單 |
| 討論 <需求> | `/spectra-discuss`：比較做法、問清楚，不改程式 |
| 把 <需求> 開成申請單 | `/spectra-propose`：寫申請單，在 Notion 建「待同意」卡 |
| 看申請單 | 讀 Notion「申請單確認」，同意的開始做，有意見的修改申請單 |
| 做 <名稱> | `/spectra-apply`：先寫測試、再實作、跑測試、部署、通知 |
| <名稱> 改成 … | `/spectra-ingest`：把新要求寫回申請單，請你再確認 |
| 看回饋 | 讀 Notion 新回饋，開申請單或直接修，回填處理結果 |
| <名稱> 結案 | `/spectra-verify` → `/spectra-archive`：規則併回、Notion 卡改已結案、寫開發日誌 |
| 修 <問題> | `/spectra-debug`：先重現、找原因；不改規則就直接修 |

## 內容同步

| 說 | AI 做什麼 |
|---|---|
| 同步 <知識庫頁面> | Notion 頁面 → 遊戲資料檔，跑測試、部署 |
| 同步 <表名> | `tools/tables/in/` 的 csv／xlsx → 遊戲資料檔，先列出改了哪些給你確認 |
| 套用調參 | 調參面板的數值寫回 `web/tuning.json` 與 Notion 數值總表 |
| 換上 <素材> | 把 `web/assets/` 的素材接進遊戲，Notion 素材狀態改「已放進遊戲」 |
| 出 <東西> 方向稿 | 依美術風格指南寫提示詞、產出方向稿 |

## 查詢與維護

| 說 | AI 做什麼 |
|---|---|
| 現在做到哪 | `spxa list`＋Notion 看板，摘要進行中與待你處理的事 |
| 量一下 <關卡> 難度 | 擬人玩家跑 30～40 局，回報掉命數、時間 |
| 檢查連接器 | 列出 Notion／Figma／Drive／GitHub 連線狀態，並確認帳號正確 |
| 更新專案首頁 | Notion 首頁的版本、預覽網址、本週進度 |
| 同步開發流 | `docs/flow/` → Notion「開發流說明」 |
| 備份 | 執行 `tools/backup-obsidian.ps1`，把 repo 文件與 Notion 匯出到本機 Obsidian |
| 部署 | 推上 GitHub，Actions 跑測試並部署，手機收到通知 |

## 進階

- `/goal <完成條件>`：讓 AI 一路做到條件達成，不中途問問題。例：`/goal 做完 item-capsules，測試全過並部署`
- 一次交辦多件：「看回饋，能直接修的修掉，要開申請單的先開好等我同意」
