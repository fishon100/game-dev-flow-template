# 各部門流程（可展開的部門泳道）設計

> 日期：2026-10-08　｜　狀態：企劃已確認方向（主圖不變，部門流程當細項展開；平台用「版本一」、遊戲用「版本 B：AI 併進企劃與程式」）

## 為什麼

主圖以「階段」為欄，看得出提案走到哪一步，但看不出**誰接在誰後面**、美術／QA／劇本在哪一步出現。企劃要的是：主圖維持，另外可以展開看各部門在每個階段做什麼。

## 怎麼做

- 流程圖頁（diagram 模式）的標準流程下方，加一個 `<details>` 區塊「各部門流程」，預設收合，展開狀態存 `console:deptOpen`。
- 展開後是一張部門泳道：**列＝部門、欄＝主圖同一組階段**（平台 7 欄、遊戲 8 欄），用同一個 `.flow` 格線，欄位上下對齊主圖。
- 連接線三種：實線＝正常推進；灰點線＝交付給另一列；紅虛線＝回去修改。線在 `<details>` 展開時才畫（收合時沒有尺寸），視窗改變與主題切換時重畫。
- 兩種模式各一份資料（部門、格子、連線），放在 `app.js` 的 `DEPT_FLOWS = { planning, game }`，渲染共用一個函式 `deptSwimlane(stages, spec)`。
